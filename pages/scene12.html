CHAPITRE 12

Les souvenirs du Sujet 07

Tu ouvres le dossier « MEMORY RECORDS — SUBJECT 07 ».

Une longue liste de fichiers apparaît à l'écran.

MEMORY 01. MEMORY 02. MEMORY 03...

Certains fichiers sont corrompus. D'autres semblent encore accessibles.

Une note technique attire ton attention.

« L'enfouissement des souvenirs du Sujet 07 reste incomplet. Les souvenirs originaux persistent et peuvent réapparaître en présence de lieux, d'images ou de sons associés au traumatisme. »

Tu comprends immédiatement.

Le symbole dans la forêt. Le couloir blanc. La porte métallique. Les voix.

Blackwood n'a pas créé ces images dans ton esprit.

Blackwood les a seulement enterrées.

Et ton retour dans le village est en train de les réveiller.

Tu continues à parcourir les fichiers.

Un enregistrement ressort de la liste : « MEMORY 06 — INCIDENT FINAL ».

Contrairement aux autres, celui-ci a été verrouillé manuellement.

Le nom de la personne ayant verrouillé le fichier apparaît encore dans les données.

« DR E. HAWKINS ».
